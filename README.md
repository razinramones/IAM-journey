# 🛡️ IAM Learning Journey

Welcome to my Identity and Access Management (IAM) learning journal.  
This repository documents my progress, experiments, and reflections as I work toward becoming an IAM Engineer.

---

## 📅 Daily/Weekly Journal Entries

### Entry Template
Use this format for each entry:

#### Date
- *Example: February 10, 2026*

#### 🎯 Goal of the Day
- What I planned to learn or practice.

#### 📝 Steps Taken
- Actions performed in order.

#### 📸 Evidence
- Screenshots, code snippets, or configuration notes.

#### 🔍 Key Concepts Learned
- IAM-related concepts I explored.

#### ⚠️ Challenges & Fixes
- Issues faced and how I solved them.

#### 💡 Reflection
- Insights gained and how this connects to IAM engineering.

#### 📌 Next Steps
- What I plan to tackle next.
